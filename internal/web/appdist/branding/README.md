# Knotera branding assets

These are the initial Knotera brand assets selected for the new product identity. The supplied reference image is the source of truth; the PNG files below are pixel crops from that source so the wordmark and icon always use the identical four-node symbol.

- `knotera-source-of-truth.jpg` — supplied reference artwork, retained unchanged.
- `knotera-logo.png` — cropped horizontal logo lockup from the source artwork, with the white background made transparent.
- `knotera-icon.png` — cropped four-node icon from the exact same source artwork, with the white background made transparent.

The mark uses four connected nodes to represent planning, delivery, review, and memory. The source artwork uses deep navy, teal, and amber on white. Keep the icon on a white or high-contrast background and generate platform-specific favicon sizes from the source PNG during the frontend build.
